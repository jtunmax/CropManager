# Remix of Tree Tracker (59)

Create a forest trees tracker app that allows users to submit geo location of where trees are planted, a reason or type of tree, and an image to verify it.  These are the basic info I want to collect for now. The login would piggyback on ArcGIS Online and only an ArcGIS Online credential would be able to sign in. The database would be an ArcGIS feature service that can be accessed when signed in.
